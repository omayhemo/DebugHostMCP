## 🏗️ System Architecture Overview

### Multi-Technology Stack Support
```
📦 Node.js      🐘 PHP         🐍 Python      📄 Static Sites    🐳 Docker
├─ Vite         ├─ Built-in    ├─ Flask       ├─ live-server     ├─ Containers
├─ Next.js      ├─ Apache      ├─ Django      ├─ http-server     ├─ Port Mapping
├─ Webpack      ├─ Nginx       ├─ FastAPI     └─ serve           └─ Lifecycle
└─ npm/yarn     └─ PHP-FPM     └─ Gunicorn
```

### Process Categories
- **🟢 Registered** - Process matches static allocation (managed and expected)
- **🔵 Discovered** - Found process not in registry (automatic detection)
- **🟠 Rogue** - Process outside known workspaces (requires attention)
- **🔴 Orphaned** - Static allocation with no running process (cleanup needed)
- **🟣 Container** - Docker container process (specialized handling)
