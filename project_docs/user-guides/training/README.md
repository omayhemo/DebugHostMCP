## 🛠️ Training Environment Setup

### Self-Paced Training Environment

#### Quick Setup (5 minutes)
```bash
# Download training environment
wget https://releases.plopdock.io/training/plopdock-training-v2.1.tar.gz
tar -xzf plopdock-training-v2.1.tar.gz
cd plopdock-training

# Start training environment  
./bin/start-training-environment.sh

# Access training dashboard
open http://localhost:3333/training
```

#### Training Environment Features
- **Pre-configured sample projects** across all technology stacks
- **Guided tutorial integration** with real process examples
- **Reset capability** to restart exercises
- **Progress tracking** for learning path completion
- **Interactive help system** with contextual guidance

### Team Training Environment

#### Multi-User Training Setup
```bash
# Setup team training environment (requires Docker)
docker-compose -f training/docker-compose.yml up -d

# Create training users
./scripts/create-training-users.sh --count 10

# Access team training portal
open http://localhost:3333/training/team
```

#### Team Training Features
- **Multi-user access** with individual progress tracking
- **Instructor dashboard** for monitoring student progress
- **Collaborative exercises** for team-based scenarios
- **Shared environments** for group problem-solving
- **Completion reporting** for training administrators
